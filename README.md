# AtividadeEclipse

Repositório criado para armazenar as atividades práticas desenvolvidas na disciplina de Programação Web para Back-End.

As atividades foram realizadas utilizando o Eclipse IDE, HTML5, CSS3, JavaServer Faces, Java, ManagedBean, ArrayList, Git, GitHub e servidor WildFly.

## Atividades desenvolvidas

### Atividade 1 — Currículo Web com HTML5 e CSS3

Nesta atividade foi desenvolvido um currículo web utilizando HTML5 e CSS3.

O projeto apresenta informações profissionais e acadêmicas em formato de página web, contendo dados pessoais, resumo profissional, formação, experiências, habilidades, projetos, idiomas e certificados.

Principais recursos utilizados:

- HTML5
- CSS3
- Organização de arquivos em pastas
- Imagem de perfil
- Links externos para LinkedIn e GitHub

---

### Atividade 2 — Formulário de Contato com JavaServer Faces

Nesta atividade foi desenvolvido um formulário de contato utilizando JavaServer Faces integrado ao CSS.

O formulário contém campos para preenchimento de nome, sobrenome, e-mail e mensagem. O projeto foi executado no servidor WildFly e acessado pelo navegador por meio de uma URL local.

Principais recursos utilizados:

- JavaServer Faces
- XHTML
- CSS3
- WildFly
- Eclipse IDE

---

### Atividade 3 — Cadastro de Usuários com JSF, ManagedBean e ArrayList

Nesta atividade foi criada uma aplicação web simples para cadastro de usuários.

O sistema permite digitar um nome, cadastrar esse nome e exibir os usuários cadastrados em uma lista na própria página. Para isso, foi utilizado um ManagedBean com ArrayList para armazenar temporariamente os dados.

Principais recursos utilizados:

- Java
- JavaServer Faces
- ManagedBean
- ArrayList
- XHTML
- CSS3
- WildFly

---

### Atividade 4 — Versionamento com Git e GitHub

Nesta atividade foi realizada a integração dos projetos com o Git e o GitHub.

O objetivo foi praticar o controle de versão, criação de repositório remoto, realização de commits e envio dos arquivos para o GitHub por meio do push.

Principais recursos utilizados:

- Git
- GitHub
- Eclipse IDE
- Commit
- Push
- Repositório remoto
